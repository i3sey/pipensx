## What's new since 1.5.0

**In short:** big games install without running out of memory, downloads stay steady, magnets actually open, and the catalog stays usable while it refreshes.

### Installs

- Big games no longer fail with "out of memory"
- Large installs start right away instead of freezing for seconds
- Pause no longer wipes install progress
- A crash or power-off resumes on FAT32 SD cards
- Free space is shown for the card you install to
- Leftover junk from failed installs can be cleaned up

### Downloads

- Speeds stay steady — good peers are not kicked too fast
- Incoming peers work, so the swarm can find you
- Dead peers stay blocked, so they are not retried every minute

### Magnets

- Game details load even when BitTorrent is blocked
- Finding peers has more time on a cold start
- After a magnet resolves, the download starts with peers already in hand
- A dead swarm says "try again later" instead of blaming your Wi-Fi

### Catalog and UI

- You can browse while the catalog refreshes
- Cancel refresh actually stops it
- Covers and scrolling are smoother
- Search is on Y, not X
- New help screen
- Wider genre picker
- Spanish translation updated
- Startup no longer freezes the UI

### Debrid

- TorBox installs faster
- TorrServer starts downloading while the install prepares
- Large TorrServer files work on Switch
- Real-Debrid installs the base game before the update
