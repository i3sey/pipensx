# pipensx 1.7.1

Changes since the last published GitLab release, 1.6.6.

## Catalog and game details

- Search ranks close title matches and compares related releases.
- Catalog cards show cached peer counts, collections, and attributed Metacritic
  scores. Multi-title releases retain their individual title IDs and versions.
- Catalog downloads can fall back to the GitHub contents API and the GitLab
  mirror. Cached snapshots and diffs are checked for provenance and age.
- Game details distinguish download size from the space required by selected
  packages, show title revisions, and link to the source topic through a QR code.
- File selection uses the available screen height, groups nested files, and
  warns about overlapping update selections before installation.

## Downloads and appearance

- Download cards show live peer statistics and retain network information while
  seeding. Secondary details can be expanded when needed.
- Verified pieces can be shared from RAM and SD storage. Peer discovery and
  incoming connections have received fixes.
- Uncached debrid torrents can remain in the provider queue.
- 7z archive header reads and writes no longer rely on unaligned integer
  pointer accesses.
- Added appearance themes and configurable accent colors. Theme changes apply
  after restarting pipensx.
- Added screen blanking during transfers and optional sleep after the queue
  finishes.

## Web Companion

- Manage downloads, browse the catalog and installed library, select files,
  change console settings, inspect logs, and run maintenance from a browser.
- Download a catalog through the phone or computer connection and upload it to
  the Switch. Local catalog JSON files are also supported, up to 48 MiB.
- Download the latest pipensx NRO and its checksum through the browser. The
  console verifies SHA-256 before staging the replacement.
- Upload a local NRO, then replace and restart through the existing updater.
  After the helper returns to HOME, launch pipensx again on the Switch.
- The update helper exits the application process, preventing forwarders from
  relaunching pipensx in the same loader session and crashing after replacement.
- Idle HTTP connections yield their slots to new requests, avoiding unnecessary
  busy responses while preserving active uploads and event streams.

Browser downloads use that device's connection, including its VPN. The VPN must
allow access to the Switch on the local network. If a source blocks browser
downloads through CORS, download the file separately and use the file picker.

## Installation

Copy `switch/pipensx/pipensx.nro` from `SDOut.zip` to the SD card, or replace the
existing NRO with the standalone `pipensx.nro`. Keep the existing pipensx data
directory to preserve settings, cached artwork, and download state. The public
build fetches its catalog on first use and does not bundle games or firmware.

For the first upgrade from an older build, use the file-copy method above. An
older build stages its own older update helper, which can still trigger the
forwarder crash after replacement. If that happens, dismiss the error and
launch pipensx again from HOME. Version 1.7.1 supplies the corrected helper for
subsequent updates.
