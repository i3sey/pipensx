## What's new in 1.6.4 (compared to 1.6.3)

**In short:** eliminated Horizon OS FS hangs and Atmosphère NCM panics during large game installs; preserved file selection access on completed downloads for grabbing extra DLCs, patches, and translations; dynamic NRO relocation and robust in-app updating; reliable Switch port deployment; fixed catalog sorting and repack classification.

### Installation & Storage Stability (Critical)

- **Upfront NCM placeholder allocation (`a69240e`):** reverted dynamic 256 MiB placeholder chunk resizing (`ncmContentStorageSetPlaceHolderSize`) back to standard upfront full-size placeholder creation (`ncmContentStorageCreatePlaceHolder`). On FAT32 SD cards, mid-stream placeholder resizing caused heavy SDMMC bus lockups, deadlocking Horizon OS FS and triggering an unrecoverable `std::abort()` panic in Atmosphère's NCM sysmodule (`0100000000000002`). This also resolves issues with 4GB+ NCA split files (`CreateOption_BigFile`).
- **Filesystem directory creation fix (`b45895d`):** normalized `mkdirs` across install and download pipelines to strip the device mount prefix (`sdmc:/`) and trailing slashes, preventing failed `mkdir` calls under libnx.

### Downloads & File Management

- **File selection for existing & completed tasks (`ee204d3`):** kept the "Select files" button accessible on the game detail card even when a release is already active or finished, replacing redundant "View download" links.
- **Incremental file downloads:** opening file selection on an existing task pre-populates previous choices, allowing users to effortlessly select and download additional DLCs, voiceovers, or community translations without deleting existing completed downloads.
- **Fast-path metainfo reuse:** opening file selection immediately reads cached metainfo without waiting for redundant network re-announces.

### In-App Updater & Path Relocation

- **Dynamic NRO relocation (`b66d441`):** resolved the active executable path from `argv[0]`, ensuring smooth in-app updates even if the NRO binary was renamed or placed in non-standard SD card locations.
- **Duplicate NRO cleanup & sync:** cleanly updates the running binary, synchronizing duplicates and removing orphaned intermediate files on the SD card.
- **In-app update notifications restored:** restored reliable update checking in Settings and accurate update prompt banners.

### Ports & Deployments

- **Direct Switch port deployment (`b45895d`):** enabled starting PortInstall tasks with manual approval from `SwitchDeployPreviewActivity` directly on the console without requiring web panel rule triggers.
- **Deployment UX improvements:** prevented duplicate actions during in-flight port operations and surfaced detailed error messages on deployment failures.

### Catalog & Classification

- **Repack & full game classification (`caf624a`):** classified full game repacks and multi-content bundles under the Games tab rather than misidentifying them as standalone updates.
- **MIG Switch & media routing:** routed MIG Switch (.xci/.xcz) and media assets to the Ports / Archives section with sanitized package types.
- **Catalog sorting regression fix (`5da20cf`):** restored proper release date and name sorting across catalog views.
- **Updated catalog snapshot:** refreshed bundled offline catalog data.
