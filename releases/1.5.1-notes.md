## What's new since 1.5.0

**In short:** steadier download speeds, metadata that resolves where it used to stall, and install resume that actually persists on the Switch SD card.

### Steadier downloads

- Peers that keep us choked get 60 s before eviction (was 20 s), so regular optimistic unchokes land instead of churning through reconnect slow-starts.
- First-block timeout is 8 s (was 4 s): half the swarm arrives over μTP, and LEDBAT plus Switch Wi-Fi routinely needs more than 4 s for the first block.
- The dead-peer blocklist holds two full tracker announces (256 entries, was 64), so dead endpoints stop being re-dialled every re-announce.

### Metadata resolving (magnet details)

- The HTTPS torrent cache is retried once on timeout — on a network that blocks BitTorrent it is the only resolve path, and one transient timeout no longer kills it.
- The DHT search window is 60 s (was 25 s): the engine only re-bootstraps after 30 s with zero good nodes, so the old window could never benefit from it on a cold start.
- Clearer failure message: refused connections prove the packets reached live hosts, so a dead swarm now says "try again later" instead of sending you to hunt for another Wi-Fi.

### Install resume

- The install journal now saves on FAT32 SD cards (rename-over-existing fails there with `File exists`), so interrupted streaming installs resume instead of re-streaming.
